Getting Started

Overview of RepFlow and core navigation

RepFlow is a minimal, privacy-focused gym workout tracker designed to help you log sets, monitor muscle group progression, and review exercise video demonstrations without distractions, ads, or account creation.

How Muscle Groups Are Organized

Exercises are categorized into 8 target muscle groups:

💪 Chest 🧍 Back 🏋️ Shoulders 🦾 Biceps 🥊 Triceps 🦵 Legs ✊ Forearms 🍫 Abs

Selecting a Muscle Group & Navigation

  • Select a Routine: From the homepage dashboard, click any muscle group card to open its dedicated workout page.
  • Return Home: Click the ← Muscle Groups button in the top header or click the REPFLOW logo at any time to return to the muscle group dashboard.

Adding a Custom Exercise

Step-by-step instructions to create custom routines

  1. Click "Add Exercise": Use the green + Add Exercise button in the top header, or the button inside any muscle group workout page.
  2. Enter Exercise Name: Type the full name of the routine (e.g. Incline Dumbbell Curl).
  3. Select Muscle Group: Choose the target group (Chest, Back, Shoulders, Biceps, Triceps, Legs, Forearms, or Abs).
  4. Select Equipment: Choose the equipment type (Dumbbell, Barbell, Bodyweight, Cable, Machine, Kettlebell, Resistance Band, or Other).
  5. Set Default Sets & Reps: RepFlow defaults to 3 sets and 12 reps. Customize these targets for your routine.
  6. Optional YouTube Video: Paste a YouTube iframe embed code (see Section 3 below) to attach a video demonstration.
  7. Click "Save Exercise": The exercise immediately appears in the chosen muscle group's workout list.
💡
Local Persistence: All custom exercises are stored locally inside your browser's persistent IndexedDB database. You can add as many custom exercises as you wish without modifying code.

Adding YouTube Videos

How to embed video demonstrations on desktop and mobile

Desktop Instructions

  1. Open YouTube in your browser.
  2. Find the exercise demonstration video you want.
  3. Click the Share button located directly below the video.
  4. Select the Embed option in the sharing popup.
  5. Copy the complete <iframe>...</iframe> embed code.
  6. In RepFlow, click Add Exercise (or click Edit on an existing card).
  7. Paste the iframe embed code into the YouTube Embed Code text area.
  8. Click Save Exercise.
  9. Click the card thumbnail or the Watch Video button to play the video inline inside the card!

Expected Iframe Structure

<iframe src="https://www.youtube.com/embed/VIDEO_ID" ...></iframe>

Mobile Tip

YouTube's mobile app may not provide the Embed option directly. If you're using a mobile phone, you can:

  1. Open the YouTube Embed Code Generator website.
  2. Enter or paste the YouTube video URL.
  3. Generate the embed code.
  4. Copy the iframe code.
  5. Paste it into the YouTube Embed Code field in RepFlow.
⚠️
Important Notes:
  • Use the <iframe> embed code, not an ordinary YouTube watch URL, when the field expects embed code.
  • RepFlow validates the embed code and extracts the video ID safely.
  • Some videos may not play if embedding is disabled by the video owner.
  • If a video does not play or shows Error 153 on local files (file://), try opening it directly on YouTube using the ↗ Open on YouTube button.

Managing Exercises

Editing, deleting, reordering, and customizing routines

  • ✏️ Editing an Exercise: Click the Edit button on any exercise card to update its name, equipment, embed code, default sets, or reps.
  • 🗑️ Deleting an Exercise: Click the Delete button on the card. A confirmation popup will ask you to confirm. Note: Deleting an exercise may also remove its associated progression history.
  • ▲ ▼ Reordering Exercises: Use the ▲ (Up) and ▼ (Down) arrow buttons in the upper-right corner of each card to organize your routine in workout order.
  • Changing Default Sets & Reps: Update default sets and reps in the Edit modal (e.g. 3 sets, 12 reps) to set baseline targets.
  • Adding or Removing Sets While Recording: While logging a workout, use the + Set and - Set buttons inside the card to add or remove sets dynamically for today's workout.
05

Tracking Workouts and Progression

How to log reps, review past sessions, and track strength over time

  1. Open a muscle group workout page.
  2. Find the exercise you are performing.
  3. Enter the reps completed for each set in the Today's Workout input fields.
  4. Add or remove sets if needed using + Set or - Set.
  5. Click 💾 Save Workout. A confirmation checkmark confirms the save.
  6. View Previous Workout to compare performance against your last session.
  7. Open 📊 History to see previous workout sessions with date stamps and set details.
📈
Progression Depth: RepFlow stores the latest progression and keeps up to 30 previous sessions per exercise, ensuring you have long-term visibility into your strength trends.

Rest Timer

Floating rest interval counter with audio alerts

The floating Rest Timer widget stays pinned to the bottom-right corner of your screen, remaining accessible while scrolling through exercises.

  • Preset Intervals: Select 30s, 60s (default), or 90s with one tap depending on your rest requirements.
  • How to Start: Click the Start button to begin the countdown.
  • How to Pause: Click Pause to temporarily freeze the countdown timer.
  • How to Reset: Click Reset to return to the preset rest interval.
  • Completion Notification: When the countdown reaches zero, the timer turns emerald green, sounds an audible chime via the Web Audio API, and shows an onscreen alert toast so you never miss your next set.

Export and Import — Device Transfer and Backup

Crucial: How to transfer workout data between devices or browsers

This section is especially important. RepFlow is an offline-first tool, so transferring workout data from one device or browser to another is accomplished through JSON backup files.

Exporting Data:

  1. Open RepFlow on the device containing the workout data.
  2. Click Export in the header.
  3. A JSON backup file (repflow-backup-YYYY-MM-DD.json) will be downloaded.
  4. Keep this file somewhere safe (Cloud storage, email, WhatsApp, or USB).

Importing Data:

  1. Open RepFlow on the new device or browser.
  2. Click Import.
  3. Select the previously exported JSON backup.
  4. Review the import summary.
  5. Choose the appropriate import mode:
    • Merge: Add imported data without clearing existing records.
    • Overwrite: Replace existing exercise and progression data with the imported backup.
  6. Confirm the import. Your data is immediately populated into the local database!
🚨
Important: RepFlow does not automatically synchronize data between devices. Each browser has its own local IndexedDB database. To transfer your workouts, manually export your data from one device and import it on another.

Always export a backup before choosing Overwrite.
08

Privacy and Data Storage

Local database isolation and zero external tracking

  • Local Storage (IndexedDB): Workout data is stored locally using IndexedDB.
  • No Account Required: RepFlow requires no login, email, password, or registration.
  • No Cloud Synchronization: There is no cloud synchronization or remote tracking. Your workout numbers belong entirely to you.
  • Browser Clearing Warning: Clearing browser data may delete saved workout information. Users should regularly export backups to prevent accidental data loss.

Frequently Asked Questions

Quick answers to common questions

Q: Will my workout data appear on another device automatically?

No. Export your data from the old device and import it on the new device.

Q: What happens if I clear my browser data?

Your locally stored workout data may be deleted. Keep JSON backups.

Q: Why is my YouTube video not playing?

The video owner may have disabled embedding. Check the embed code or open the video directly on YouTube.

Q: Can I add my own exercises?

Yes. Use the Add Exercise button.

Q: Can I change sets and reps later?

Yes. You can edit default values and customize the sets for individual workouts.

Q: Where can I see my previous workouts?

Use the History button on the relevant exercise card.

Q: Can I use RepFlow without creating an account?

Yes. It works without registration.
